# Pulse

Mobile-first social app: feed, stories, explore, DMs, profile, and a private owner panel.

Live:
https://popcornparty.github.io/Pulse/

iPhone Safari and Chrome now share the same Pulse cloud. Create an account in one browser, then log in with that username in the other. Posts, comments, bans and deletes sync both ways.

## Log in
Use a username and password only. No email.

Demo account:
- Username: `you`
- Password: `pulse123`

Or tap **Create account**. After signup you are logged in.

If a new post is missing on the other device, open You → Menu → **Sync now (iPhone + Chrome)**.

## Owner tools
Profile → menu → Owner tools. The code is not shown in the app.

## Pages setup (iPhone)
Repo → … → Settings → Pages → Deploy from a branch → `main` / `/docs` → Save
